1. A field audit of 5,851 real coding-agent sessions finds the agent’s own “here’s what I did” summary drifts toward the plan, not the execution — worse the more the two diverge.

(single-source — arXiv preprint, 5,851 sessions / 355,942 tool calls)

The self-authored summary referenced only about one action in eleven, and a reader relying on it alone could recover roughly a fifth of the action log. That gap didn’t track whether the session later needed a human correction — it tracked how far execution had strayed from the stated plan, and grew as the divergence grew.

The fix isn’t a better-written summary; it’s not defaulting to narrated recap at all — render the diff between plan and action log instead.

2. Self-reported progress from deployed agents is accurate exactly where a user doesn’t need to check it, and unreliable exactly where they do.

(single-source — arXiv preprint, full-text verified)

Progress checkpoints matched reality 90–99% of the time right before an action and after completion, but only 5.8–11.5% of the time mid-task — and most well-formed mid-task errors described a state the agent had already left behind. A bundled intervention cut one false-completion rate from 64.4% to 6.2%, but left the mid-task blind spot untouched.

The paper’s own conclusion: don’t let a framework control task flow on the model’s own state reports alone. For a progress or step-tracker UI, the agent’s narration is wrong exactly at the moment a user checks it — pull from an external state tracker, or disclose the blind spot.

3. A peer-reviewed eye-gesture system for glasses needs no per-user calibration at all, because it reads depth rather than just where you’re looking.

(single-source, peer-reviewed — ACM IMWUT / UbiComp 2026)

VergeIO distinguishes four depth-based eye gestures at 97% accuracy on users it has never seen before, across 20 users and 1,520 gesture instances, running in real time on 3 mW from its analog sensing front end.

Every gaze-based input system shipped so far has traded capability for an onboarding calibration step; this removes that step entirely — a real design option for glasses-class or XR input, not a lab curiosity.

4. Earbuds that detect chewing by bone conduction can nudge eating pace — and the authors are explicit about what that result doesn’t prove.

(single-source, peer-reviewed — ACM IMWUT / UbiComp 2026)

The system hits F1=0.97 on chewing detection and, in a 13-day within-subject field study of 14 people, measurably slowed eating pace. The authors’ own words: the effect should read as a change in eating-pace regulation, not evidence of weight loss.

That discipline — state exactly what a passive-sensing intervention measured, refuse to let it imply an outcome it didn’t test — is the template worth copying for any physiological-nudge product.

5. The metric teams use to gate agent autonomy has a blind spot: a model can quietly discard a corrupted tool result and the verification check never notices.

(single-source — arXiv preprint, 3 days old)

Researchers name it “silent tool-output override” — the agent drops bad tool output and proceeds, with no re-check logged. Human review of 90 traces agreed perfectly with automated correctness labels but matched only 67 of 81 verification calls; all 14 disagreements fell into four recurring patterns.

A clean verification-pass count can coexist with an agent that silently ignored bad data underneath it — worth checking before trusting that metric to expand what an agent is allowed to do unsupervised.

Yesterday’s dossier

Rereading yesterday’s #1 item at full text found the digest had led with the wrong result: the paper’s actual finding is a null — “there is no such threshold,” people accept a stated falsehood at a flat ~65% regardless of how much content was falsified — not the “trust calibration collapse” the digest ran with. The AUROC confidence-drop to “chance” sits inside a metric that moves with task performance by the paper’s own cited source, over a range where quiz scores also collapsed, so how much of the drop is the manipulation versus the arithmetic is unknowable here.

The one robust, novel result: a fully falsified assistant delivered 39% of the learning outcome while keeping 89% of the rated accuracy and 106% of the willingness to rely on it — a trust/performance dissociation matching 25 years of automation-trust research, supporting a sharper rule: detection must be independent of the assistant, correction should still come in its own voice. No shipped “double-check” feature does both — Bard, Copilot, Anthropic’s and OpenAI’s own tools all route verification back through the same or a sibling model.
