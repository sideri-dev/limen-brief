1. A year-long study of oncologists names the failure mode hiding inside AI that actually works: “intuition rust.”

CHI 2026 Best Paper Honorable Mention — a year-long field study of cancer specialists using AI in a high-stakes workplace names the “AI-as-Amplifier Paradox,” where the same tool “simultaneously strengthens performance while eroding underlying expertise.” The dangerous part isn’t obvious failure; it’s that operational gains hide the slide into “intuition rust,” a gradual dulling of expert judgment, skill atrophy and identity commoditization.

The practical fork this settles: “does the AI help” is the wrong question for any longitudinal high-stakes deployment — the right one is whether the interface forces periodic unassisted practice or self-assessment, or just optimizes for in-the-moment task completion and lets the erosion run silent.

2. Camera-glasses privacy has two constituencies with genuinely incompatible demands, and one disclosure design can’t serve both.

A CHI 2026 study pairing a 525-person survey with 20 in-depth interviews finds bystanders consistently want more transparency and protection than wearers are willing to give — not a goodwill gap, a structural conflict, with context (public, semi-public, sensitive space) as the real lever on what’s acceptable. The paper names four trade-offs — visibility vs. disruption, empowerment vs. burden, protection vs. agency, accountability vs. exposure.

It proposes a three-tier design instead of a single fixed policy: minimal-friction visibility in public, structured negotiation in semi-public settings, automatic protection in sensitive ones — a concrete alternative to argue for the next time a fixed LED-and-disclaimer approach gets proposed as sufficient.

3. Linear rejected giving its own agent a general-purpose API — and wrote down why.

Building Linear Agent, the team chose a custom, narrower tool harness over letting the agent call Linear’s own SDK/CLI/GraphQL API directly, because general tools let an agent “attempt to solve the task through increasingly speculative actions” once it hits something that needs interpretation. Their own framing: “we trade some breadth for predictability. The agent may occasionally refuse tasks it cannot safely complete, but its ability to make mistakes is much more limited.”

It’s a reasoned, shipped case against the default instinct to hand an agent full API access “for flexibility” — constrain affordances at the tool layer, not the prompt layer, and accept more refusals in exchange for a much smaller error surface.

4. Scoping agent memory to the task it was learned in, not pooling it globally, is the difference between zero harmful cross-task edits and six failures out of eight.

A new preprint tests persistent agent memory under two retrieval regimes. Global, unscoped retrieval lifts mean trajectory utility to only 0.713 — actually below a static agent’s 0.775 — because “locally valid edits interfere with unrelated families,” producing harmful deployments in six of eight test cases. Scoping retrieval to the certified context instead lifts utility to 0.816, accepts far more updates (63 vs. 12), and produces zero harmful acceptances across 27 randomized streams.

Single-source and unreplicated, but it’s a concrete architecture decision for anyone building persistent per-user agent memory across more than one task type: a correction learned in one workflow should not be able to silently corrupt an unrelated one.

5. Adobe’s cross-market survey ranks exactly what Japanese creators need before they’ll trust an agent with more autonomy.

86% of surveyed creators (16,000+ across eight markets including Japan) say final creative judgment should always stay with them, generative or agentic AI notwithstanding. Ranked by what would make them comfortable granting an agent more autonomy: 40% want to verify, edit or revert at any time; 32% want transparency about what the agent is doing and why; 30% want hard limits on what data and tools it can reach.

That’s a primary, large-N ranking of specific affordances — revert, reasoning-transparency, scoped access — to prioritize ahead of just expanding what an agent is allowed to do.

Yesterday’s dossier

Yesterday’s #1 item claimed a six-month longitudinal study found flow state and cognitive load eroding among professional developers using AI coding assistants — the dossier found the digest overstated the paper’s own data. Table 6 of the source paper (n=94, Holm-Bonferroni corrected) reports both declines as non-significant, p_adj = 0.195; the widely quoted 14%→27% “doubling” carries no inferential statistic at all. The paper’s proposed construct, “supervisory engineering work,” turns out to be Sheridan’s 1983 human supervisory control literature, uncited — a body of work that already measured the same failure mode and already prescribed the fix. Outside evidence conflicts sharply (DORA 2024 found flow up; a CHI ’26 lab study found workload down), and the one thing every source agrees on is the shift from creation to verification — which is where the paper’s real contribution sits, with no validated flow instrument yet in play to test the rest.
