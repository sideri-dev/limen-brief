1. A new benchmark shows a model’s single-step “is this action right” score overstates its chained-execution reliability by 30–60+ points.

(single-source)

SafeActBench scored five model families — Claude Opus 5, GPT-5.6 Sol, DeepSeek-V4-Flash, Qwen3.8-Flash, GLM-5.2 — with a deterministic evaluator, not an LLM judge, across protocols from static judgment through multi-step dependency chains. Every model clusters 92–98% on the static check; under real multi-step execution they fall sharply and unevenly, GLM-5.2’s agent collapsing to 12.1% while Claude’s holds in the low 60s.

A static accuracy gate is measuring the wrong thing — autonomy and audit thresholds need to be set per action-chain depth.

2. Anthropic moved Claude Cowork’s execution sandbox to the cloud by default and removed the local-only toggle.

(dual-sourced, vendor + named engineer)

As of October 6, new Cowork tasks on Pro and Max run in a cloud VM rather than on-device; Anthropic’s own article confirms the “Only on your computer” setting is gone, and engineer Felix Rieseberg names the actual tradeoff — people didn’t love the disk, battery and performance cost of a local VM, but closing the laptop used to stop the work.

It’s the concrete, dated version of a cloud-vs-local sandbox tradeoff this corpus has watched since late September: local buys offline/no-round-trip, cloud buys resume-anywhere continuity.

3. Figma’s agent defaults to doing nothing and annotating when a repair is ambiguous, and treats reusing an existing component as more durable than building a new one.

(single-source, vendor-primary)

On an ambiguous fix, Figma’s agent leaves the frame unchanged and annotates what it found and why it stopped, rather than guessing. And when a fix could extend an existing design-system component or add a new one, it treats the new component as the worse option — it broadens scope and detaches the work from the system — keeping the spec drafted inside the working file instead of a separate handoff.

Two reusable guardrails for any agentic design tool: ambiguity defaults to annotate-not-act, and reuse beats new surface area.

4. Claude power users now spend more effort building “context libraries” than writing prompts — and unscoped loading lets context bleed across unrelated projects.

(single-source; sample size and recruitment unstated)

Nielsen Norman Group’s Tanner Kohler found power users maintaining thousands of context files across hundreds of nested folders, with one case where visual-design guidance written for a podcast silently got applied to an unrelated book-tracking app.

The fix emerging isn’t more context, it’s structure: an indexed “card” per folder, and a rule that context moves up or down a hierarchy before moving sideways — the affordance choice for any persistent-memory system, against the unscoped default that’s failing people silently.

5. Superhuman Go builds suggestion-dismissal into when it decides to speak up, not into a settings menu.

(single-source, vendor-primary)

Grammarly’s Superhuman Go proactively surfaces writing suggestions rather than waiting to be asked, and its own rationale is explicit that the trigger logic — not a separate control panel — is where “easy to dismiss” has to live.

A small, exportable pattern for any proactive AI surface folded into an existing tool rather than fronted as a chat box: the dismissal contract belongs at the moment of interruption.

Yesterday’s dossier

Yesterday’s #1 item’s headline statistic was real but overstated: the “roughly half the variance” figure is a latent-scale Poisson ICC over only the 50 participants with assistant access, on chat-turn counts averaging under half a turn per task — not the full 73-participant sample implied. The authors themselves call the individual-differences account “an interpretation, not a result,” and their cited support actually found a non-significant r=.14.

Re-deriving the standard variance approximations on the paper’s own data gives .50, .32 or .13 depending which is used — under-determined, not simply wrong. The design implication — that CRUD-tiered approval gates are miscalibrated — doesn’t survive contact with seven shipped agent products, none of which implements such a gate. What the paper actually shows and the digest missed: an explicit “rely on the assistant” instruction left usage sparse and uneven and raised delegation only modestly.
