1. A real care-home transcript shows a voice assistant’s own “helpfulness” is what breaks the conversation, not its silence.

(single-source — CUI ’26, ACM SIGCHI, double-anonymous peer review confirmed)

A CUI ’26 paper built from conversation analysis of a learning-disabled user and her LLM smart speaker in a real deployment finds the system’s repeated repair attempts — not silence — generate the trouble. A flat “No” gets answered with “I didn’t quite catch that, would you like me to set a reminder for your bath or shower?” instead of being accepted as a complete turn. Earlier in the same transcript: “Sentai, you need to think I’ve got a learning disability.”

ACM blocked direct access; corroborated instead through Crossref, OpenAlex, Semantic Scholar and a co-author’s own supporting document, matching the transcript verbatim. For a care or accessibility assistant: treat a short valid answer as a finished turn, and cap how much the system elaborates past it.

2. “The system prompt always wins” doesn’t hold on the tasks where it matters most.

(single-source — arXiv preprint, 1,887,356 replies across 14 models)

A study sending 1,887,356 replies across 14 open-weight models tested only how an instruction is delivered — position, role, label — holding the text fixed. On ordinary conflicts, whichever instruction arrives first usually wins.

But on tool-use and file-write tasks specifically, a plain user message sent first beats a system-role “policy-first” instruction in every model tested, and models flag the conflict at most 2.92% of the time. A safety boundary encoded only as “put it in the system prompt” doesn’t hold where it counts; enforcement needs to live outside the model.

3. Human reviewers catch fewer false alarms exactly as a system gets tuned stricter — and it depends which algorithm is wrong.

(single-source — arXiv preprint, 801 human reviewers)

801 human reviewers were tested against face-recognition false positives across three security-threshold settings from four commercial algorithms. Reviewers do reduce false positives, but their catch rate falls as the threshold tightens, and it varies by which algorithm produced the error.

A measured limit on “human in the loop” for any high-stakes flagging system: the backstop weakens as the system is tuned toward fewer, higher-confidence flags, and the underlying model choice is itself part of the oversight design, not just the review screen.

4. A tool-output transparency layer that ranks evidence by actual influence, not raw chain-of-thought, tested well and proved itself causally.

(single-source — arXiv preprint / HCII proceedings, n=50)

Filtered Decision Logs rank what an agent’s tools returned by measurable signals — closeness to the final answer, relevance, persistence, structural proximity — instead of dumping the full trace or a vague summary. Across career advice, investment analysis and travel planning, 50 participants rated the ranked evidence helpful 92% of the time.

Removing the top-ranked source changed the answer more than removing a low-ranked one — causally real, not just preferred. A validated alternative for explaining an agent’s tool-use reasoning, short of either a raw trace or an opaque gloss.

5. A trained consistency score cuts an agent’s run-to-run flakiness by a third to a half, without needing labeled ground truth.

(single-source — arXiv preprint)

Recursive Semantic Divergence is a fine-tuning reward signal needing no correctness labels — it only measures how consistent an agent’s behavior is across repeated runs. Used that way, it cut task-progress variation from 132% to 91% on one benchmark and from 90% to 44% on another.

For any shipped agent, the same request producing visibly different behavior run to run is itself a UX failure, independent of whether any single run was “right” — a measurable fix, with no labeling pipeline required.

The structural claim still stands — Toyota’s, Kia’s and Volvo/Polestar’s manuals, plus UN regulation and Euro NCAP’s protocol, confirm a vehicle can legitimately show “operating” while not perceiving the lane, and no scheme scores the indicator’s truthfulness, only its placement. The actual fix is narrower than “escalate the display”: re-sorting the same alerts across tiers cut false alarms from 57% to 12.5% elsewhere, but the digest’s own proposed trigger — low confidence plus hands off the wheel — has never been tested, and a 2026 CHI paper calls exactly that condition underexplored.
