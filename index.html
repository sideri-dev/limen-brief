A brief demo of "I can see you" does what a face is supposed to do — without the anthropomorphization tax.

A HAI Symposium 2026 experiment put a faceless, deliberately minimal-design agent in front of 40 participants and found zero reflexive gaze-cueing effect — until half the group got one short pre-interaction where the agent turned toward a held-up piece of paper, showing it could "see." That group alone showed a real interaction effect (p=0.022) and reaction-time differences that vanished entirely without the demo (p<0.001 vs. p=0.721), plus higher anthropomorphism scores from an identical physical stimulus.

The finding upends the assumption that faces or cuteness are what earn social engagement from users — a brief, honest disclosure of what the system can perceive did the same work, and the authors argue it sidesteps the over-anthropomorphization risks (parasocial dependency, lost critical distance) that a face invites. For anyone building a chat or voice avatar, gaze-following looks like a usable implicit signal for whether a user currently holds an "intentional stance" toward the agent — something to read, not just something to design.

One tunable "assertiveness" slider beat both raw confidence scores and fixed autonomy settings for deciding when a robot should act.

WAFFLE, HRI 2026's Best Paper in the Systems track, predicts bite timing for a feeding robot from a wearable's read on head movement, chewing, and talking, then converts that prediction into a stop/go decision through a single user-adjustable threshold. Across 15 participants it matched or beat baseline approaches on feeling of control, robot understanding, and workload, and a follow-up generalization study ran it with motor-impaired participants using a different robot arm in their own homes.

The specific move worth stealing is the interface, not the sensor: one tunable knob rather than a confidence number nobody can act on or a fixed autonomy setting nobody can adjust — a pattern that generalizes to any assistive system deciding when to act on an ambiguous physical cue.

Hybrid interfaces don't self-regulate risk — who the user is predicts delegation far better than what the task is.

A 73-person study at HAI 2026 put people through 16 CRUD tasks in a CMS with an MCP-connected agent, comparing traditional-only, AI-first, and hybrid conditions. AI assistance cut clicks and navigation but not total task time, and there was no relationship between how risky a task was and how much people delegated to the agent — individual differences accounted for roughly half the variance (ICC=.50).

That kills the comfortable assumption that a hybrid GUI/agent interface will naturally gate itself toward caution on high-stakes actions. Approval and confirmation logic needs to be set explicitly by task risk, and the more useful lever for tuning delegation is a per-user default, not a per-task heuristic.

Linear rejected giving its coding agent broad API access on purpose — and named the tradeoff.

Building Linear Agent, the team chose not to hand it the Linear SDK, a CLI, or direct GraphQL access, instead encoding constraints into the agent's tools themselves rather than writing them into a prompt. Their own framing: "we trade some breadth for predictability," describing it as replacing software's old goal of predictability with a more deliberate form of control.

It's a clean, reasoned counter to the default instinct of giving an agent maximum tool access and trusting the model to behave — tool-level constraint beats prompt-level instruction once you're operating at scale.

Claude's computer-use tool can now take several actions per model call — the latency tax on GUI agents just dropped.

Anthropic made computer use, the Skills API, and the Files API generally available, and the headline change is architectural: the updated tool lets Claude execute multiple actions per turn instead of one action per model call, meaning fewer round trips and less time per task. Computer use is also now eligible for HIPAA-regulated workloads under Anthropic's BAA. One customer, Asteroid, is quoted cutting a workflow from 32 minutes to 13.

The practical shift is that GUI-automation agents can now plausibly sit inside a synchronous, user-facing flow instead of needing to run async in the background — and the HIPAA eligibility changes how much of a regulated workflow can be delegated versus gated behind a human.
