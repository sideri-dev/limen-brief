1. A UIST 2026 technology probe swaps the prompt box for material gestures — stretch, sculpt, cluster — to steer generative AI.

MaterialVellum maps material properties like elasticity and malleability onto spatial and proportional constraints on generative output, letting a designer shape AI output with multi-touch gestures instead of a prompt. Demonstrated across urban-design, flower-arrangement and graphic-design probes, though the study is qualitative only (N=10) — a direction, not yet a shipped pattern.

It’s the first concrete, peer-reviewed alternative to the text box worth tracking as a UI primitive.

2. Figma Weave’s co-founder names the real design fork in creative AI tools: labor versus thinking.

(single-source — vendor)

Itay Schiff argues some friction in a creative workflow is just labor — hand it to the machine — while other friction is where the thinking happens, worth protecting. Weave ships two named modes: “open mode” for exploring and drafting, “closed mode” for committing and repeating, illustrated with a Gaussian-splat campaign whose first AI pass was “far from finished.”

A reusable rule for scoping which steps an assistant should own outright versus merely propose.

3. Attio built its AI assistant as code inside the product, not a chat panel, and refuses to lock to one model vendor.

(single-source — vendor; ~8 months old, kept for tradeoff specificity)

“Ask Attio” is “a system embedded into the core of the product,” not a standalone chat interface — and it runs across Anthropic, Vertex AI and OpenAI behind a shared abstraction rather than one vendor. It also names a real cost: batching the full response avoids visual noise but gives up streaming’s responsiveness entirely.

A concrete counter-example to “ship the chat panel first.”

4. GitHub’s Copilot routing layer treats “which model to call” as an optimization problem — and names what hiding drafts costs the user.

(single-source — vendor)

Project HydraFusion dynamically constructs a task-specific path across multiple models rather than picking one best model, and GitHub states the tradeoff plainly: “waiting without enough visibility is a real trade-off for developers.” Against Claude Opus 5 it gains on TerminalBench 2.1 (+4.9 points, 67% cheaper) but loses slightly on DeepSWE and CheckpointBench — the benefit isn’t uniform across tasks.

Independent reporting puts this live as “Copilot Fusion” since October 28, 2026 — not stated on GitHub’s own page.

5. Profiling the actual phone beats asking a frontier model to guess its constraints — by up to 60 points.

(single-source — arXiv preprint)

Mobile AI Factory’s on-device search against real hardware measurements beats two five-shot frontier models on five tasks and matches them on three more, at 19× less GPU time than training every variant exhaustively. Given only the spec sheet, Claude Opus 5.5 misses real requirements in a quarter of easy/moderate cases and 60% of hard ones.

Don’t let a model guess a device budget it has never touched — measure it.
